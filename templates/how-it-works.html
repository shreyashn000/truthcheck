THE TECHNOLOGY

How does
TRUTHCHECK work?

TRUTHCHECK uses Natural Language Processing and Machine Learning to classify submitted news text according to patterns learned from labelled news data.

MACHINE LEARNING PIPELINE
01

News Dataset

A labelled dataset containing examples of real and fake news is used to train and evaluate the Machine Learning model.

↓
02

Data Preprocessing

The text data is cleaned and prepared. Missing values and duplicate content are handled before model training.

↓
03

TF-IDF

Term Frequency–Inverse Document Frequency converts news text into numerical features that can be processed by the classifier.

↓
04

Logistic Regression

The classifier learns patterns associated with the labelled real-news and fake-news examples in the training dataset.

↓
05

Prediction

New news text is transformed using the trained TF-IDF vectorizer and passed to the trained classification model.

↓
06

Result

The website displays an AI-assisted result as Likely Real, Likely Fake or Uncertain, together with a confidence score.

TECHNOLOGY STACK

Built with
practical technologies.

01

Python

Used for data processing, Machine Learning model development and backend integration.

02

Scikit-learn

Used for TF-IDF feature extraction, Logistic Regression and model evaluation.

03

Flask

Provides the Python-based web application backend and connects the website to the model.

04

HTML / CSS / JavaScript

Used to create the responsive user interface and interactive news-analysis experience.

05

Pandas

Used to load, clean, transform and analyse the news dataset.

06

Joblib

Used to save and load the trained Machine Learning model and TF-IDF vectorizer.

UNDERSTANDING THE RESULT

Three possible
outcomes.

01

LIKELY REAL

The model identifies the submitted text as being more closely associated with the real-news patterns learned during training.

02

LIKELY FAKE

The model identifies the submitted text as being more closely associated with the fake-news patterns learned during training.

03

UNCERTAIN

The model does not have sufficient confidence for a strong classification, so additional verification is recommended.

IMPORTANT LIMITATION

A prediction is
not a fact-check.

TRUTHCHECK is an educational AI-assisted classification system. It learns patterns from its training dataset and applies those patterns to new text. It does not independently verify the truth of real-world claims, access every news source on the internet, or guarantee that an article is factually accurate.

Users should therefore verify important information using reliable sources, official statements and independent reporting before making decisions or sharing the information.
